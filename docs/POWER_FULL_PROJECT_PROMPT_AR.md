# برومبت مشروع باور لإدارة معارض السيارات

استخدم هذا النص كوثيقة مواصفات كاملة عند تطوير أو توسيع نظام **باور لإدارة معارض السيارات**.

## اسم النظام

- الاسم العربي: **باور**
- الاسم الكامل: **باور لإدارة معارض السيارات**
- الاسم الإنجليزي الاختياري: **POWER Car Showroom Management System**

## فكرة النظام

أريد تصميم وتطوير نظام احترافي ومتكامل لإدارة معرض سيارات، يعمل على الويب و iPhone و Android و Windows Desktop، ويدعم العمل بدون إنترنت Offline First، مع مزامنة تلقائية عند رجوع الإنترنت، وبدون أي اشتراكات شهرية أو SaaS أو خطط أسعار. النظام مملوك بالكامل لصاحب المعرض، مع كود مصدر كامل وقابل للتشغيل على سيرفر خاص أو استضافة خاصة.

## الهوية البصرية

أريد شعاراً احترافياً باسم **باور** مناسباً لبرنامج إدارة معارض سيارات:

- دمج رمز سيارة حديثة مع إحساس بالقوة والسرعة والإدارة.
- استخدام النص العربي "باور" كعنصر أساسي.
- يمكن إضافة كلمة POWER بشكل صغير.
- مناسب لتطبيق iPhone و Android و Windows.
- مناسب للموقع ولوحة التحكم والفواتير والعقود والتقارير.
- ألوان الهوية: أسود فاخر، ذهبي معدني، أبيض، رمادي، وأزرق داكن اختياري.

## العمل بدون إنترنت

يجب أن يعمل النظام حتى عند انقطاع الإنترنت. كل جهاز يحتوي على قاعدة بيانات محلية، ويستطيع المستخدم:

- عرض السيارات.
- إضافة سيارة.
- تعديل بيانات سيارة.
- إضافة عميل.
- إنشاء حجز.
- تسجيل دفعة قسط.
- إضافة مصروف.
- رفع صور ومستندات محلياً.
- إنشاء فاتورة مبدئية أو معلقة.

كل عملية تحفظ في طابور محلي، وعند رجوع الإنترنت يتم إرسالها إلى السيرفر، واستقبال تحديثات باقي الأجهزة، مع منع فقدان البيانات.

## المزامنة

- مزامنة تلقائية عند توفر الإنترنت.
- مزامنة يدوية بزر "مزامنة الآن".
- عرض حالة الاتصال: متصل، غير متصل، جاري المزامنة.
- عرض آخر مزامنة.
- عرض عدد العمليات المعلقة.
- إعادة المحاولة عند فشل المزامنة.
- رفع الصور والمستندات عند رجوع الاتصال.

## حل التعارضات

إذا عدل أكثر من مستخدم نفس البيانات بدون إنترنت:

- حفظ نسخ التعديلات.
- تنبيه المدير بوجود تعارض.
- اختيار النسخة الصحيحة أو اعتماد آخر تعديل حسب الوقت والصلاحية.
- تسجيل كل التعارضات في سجل النظام.

## المتطلبات التقنية المقترحة

- Web Frontend: Next.js أو React.
- Mobile/Desktop: Flutter لتطبيق iPhone و Android و Windows من نفس الكود.
- Backend: NestJS أو Laravel.
- Database مركزية: PostgreSQL.
- Database محلية: SQLite.
- Web Offline Storage: IndexedDB.
- Authentication: JWT + Refresh Tokens.
- API: REST أو GraphQL.
- Reports: PDF و Excel.
- Deployment: VPS أو سيرفر خاص.
